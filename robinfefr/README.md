# Číselníky (Robinfefr)

Samostatná Next.js aplikace: jaké zboží je na jakém umístění a na jakém účtu.

Tuto složku zkopírujte do lokálního GitHub Desktop repozitáře **Robinfefr** (soubory z `robinfefr/` přímo do kořene toho repa, ne jako vnořenou podsložku).

## Do GitHub Desktop

1. Otevřete repo **Robinfefr**.
2. Zkopírujte sem vše z této složky (`package.json`, `src/`, `vercel.json`, …).
3. Commit to main → Push origin.
4. Na [vercel.com](https://vercel.com) → Add New → Project → vyberte **Robinfefr** → Deploy.

Volitelně v Vercelu nastavte `CISELNIKY_EMAIL` a `CISELNIKY_PASSWORD`. Bez nich platí vestavěné přihlášení.

## Localhost

```bash
npm install
npm run dev
```

Otevřete [http://localhost:3000](http://localhost:3000).
